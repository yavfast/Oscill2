# Виправлення алгоритму обчислення частоти та періоду

## Дата: 2 жовтня 2025 р.

## Проблема
Алгоритм обчислення частоти та періоду в `web_oscill/calculations.py` використовував простий метод zero-crossing (перетинів нуля), який:
- Не фільтрував шум
- Був менш точним для зашумлених сигналів
- Не відповідав перевіреній Java реалізації в `OscillData.java`

## Рішення
Повністю переписано алгоритм відповідно до `OscillData.java` метода `calcFreq()`.

### Новий алгоритм (Segment Analysis Method)

1. **Обчислення порогу**: Середнє значення всіх семплів використовується як поріг
2. **Сегментація**: Розділення сигналу на позитивні (вище середнього) та негативні (нижче середнього) сегменти
3. **Фільтрація шуму**: Видалення коротких сегментів (менших за середню довжину)
4. **Перевірка надійності**: Потрібно мінімум 3 сегменти для обчислення частоти
5. **Обчислення періоду**: `(середня довжина позитивних + середня довжина негативних) × час_на_семпл`
6. **Обчислення частоти**: `1000 / період_мс` (для переведення в Гц)

### Нові функції

```python
def calculate_segments(samples, threshold) -> tuple[List[int], List[int]]
```
Визначає довжини позитивних та негативних сегментів відносно порогу.

```python
def calculate_average(values) -> int
```
Обчислює цілочисельне середнє значення списку.

```python
def filter_short_segments(segments, min_length) -> List[int]
```
Фільтрує короткі сегменти для видалення шуму.

```python
def calculate_frequency_and_period(samples, t_step_ms) -> Dict
```
Головна функція обчислення частоти та періоду з використанням сегментного аналізу.

### Результати тестування

```
100 Hz sine wave, no noise
  Expected: 100 Hz
  Measured: 101.01 Hz (error: 1.01%)
  
100 Hz sine wave, high noise  
  Expected: 100 Hz
  Measured: 103.09 Hz (error: 3.09%)
  
1 kHz sine wave, no noise
  Expected: 1000 Hz
  Measured: 1020.41 Hz (error: 2.04%)
```

### Переваги

✅ **Стійкість до шуму** - фільтрація коротких сегментів видаляє випадкові перетини
✅ **Точність** - похибка в межах 1-3% для чистих сигналів
✅ **Надійність** - перевірка мінімальної кількості сегментів
✅ **Відповідність Java** - ідентична логіка з `OscillData.java`
✅ **Edge cases** - коректна обробка порожніх даних, константних сигналів, коротких вибірок
